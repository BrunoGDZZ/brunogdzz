A coursework project exploring social interactions through Java classes and a menu-driven interface.

A command-line social platform

abUTA is a text-based social media platform with threaded posts, private messaging, muting, and account blocking. The focus is on how those behaviors fit together in a larger Java program.

Without a graphical interface taking center stage, the design of the underlying objects becomes especially visible. Accounts, posts, messages, and groups each need clear responsibilities and meaningful relationships.

The core interactions

  • Public conversations. Posts and threads give users a place to share and respond.
  • Private messaging. Direct messages model conversations between accounts.
  • Account controls. Muting and blocking provide ways to manage interactions.
  • Menu-driven navigation. A command-line interface connects users to the application’s features.

Data modeling and code structure

This project is an opportunity to practice data modeling and object-oriented design beyond small, isolated exercises. The repository includes separate account, message, and menu packages, alongside test and demo programs.

It remains a work in progress as I develop a better understanding of how to organize growing applications.
