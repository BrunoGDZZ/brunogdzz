Turn-based survival in Java

The classic Robots premise is straightforward: survive on a board while robots move toward you each turn. Recreating that behavior is a useful exercise in translating a set of rules into a working program.

This project started with text-based gameplay and adds a desktop interface using Java Swing. The board makes the state of the game visible, while movement and survival rules drive what happens next.

What I worked on

  • The game board. Representing the player, robots, and their positions on a grid.
  • Movement behavior. Updating robot positions in response to the player’s turn.
  • Game state. Applying survival rules and providing a way to start another round.
  • The desktop interface. Connecting Swing controls and rendering to the underlying game logic.

Learning through a familiar game

A small game creates an immediate feedback loop: change a rule or movement routine and you can see the result. It is a practical way to work on object-oriented programming, event-driven interfaces, and reasoning about state changes.

The project remains in progress as I continue working on the structure and behavior.
