A software engineering project developed with an Agile approach.

An Android marketplace

Auction 6 is an auction-house-style app for car parts. Users can create an account, browse a marketplace, post listings with photos, and interact with bidding and buy-now options.

The project brings together a Compose interface, application navigation, and a local SQLite database accessed through Room. The repository separates screens and routes from the data layer, with entities and data-access objects for users, listings, and bids.

Inside the application

  • Accounts and navigation. Registration, login, and verification screens provide an entry into the marketplace.
  • Listing creation. Sellers can describe a part, choose a category, attach a photo, and set pricing and duration.
  • Bidding and buying. Listing details bring together the current price, bid history, and purchase actions.
  • Local persistence. Room entities and DAOs organize users, listings, and bids in SQLite.

What this project explores

A marketplace is more than a collection of screens. A listing has to connect to a seller; a bid has to connect to a listing; navigation has to carry the right information between them. This project was a way to practice connecting those pieces in an Android application.

Working in an Agile structure also made iteration part of the process: turn a larger feature into smaller tasks, implement it, and revisit the result.
