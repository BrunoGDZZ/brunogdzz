Originally built with Jekyll. Reworked as a static site to make development, previewing, and hosting simpler.

Project pages and navigation

This site brings together my projects, coursework, and contact details. It uses a two-column introduction, a project grid, and shared styles across the homepage and project pages.

Each project has its own case study, with context, a closer look at the implementation, and a direct path to the source.

Site features

  • A responsive layout. The navigation, project grid, and typography adapt from desktop to phone.
  • Project filtering. Visitors can browse all work or focus on mobile, Java, and web projects.
  • Light and dark themes. A saved preference follows visitors between project pages.
  • Accessible interactions. Semantic sections, keyboard focus states, a skip link, and a native dialog support navigation.
  • A canvas rhythm game. A 30-second rhythm game uses canvas, optional audio, and a locally saved best score.

Static hosting and local preview

The current site runs directly from HTML, CSS, and JavaScript. It needs no package installation or build step, and GitHub Pages can serve it directly with .nojekyll.

A small PowerShell preview server makes it possible to inspect changes locally before publishing. Relative links also keep the site usable under the repository’s GitHub Pages path.
